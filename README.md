# cars24-used-car-analysi
# 🚗 Cars24 Used Car Data Analysis & Web Scraping

A Python-based data analysis project that scrapes used car data from Cars24 and performs exploratory data analysis to identify patterns in car availability, locations, fuel types, transmission types, registration years, and prices.

## 📌 Project Overview

The used car market in India is growing rapidly. This project uses web scraping and exploratory data analysis to collect and analyze used car listings from Cars24.

The project focuses on:

- Scraping used car information from Cars24
- Creating a structured dataset
- Cleaning and preprocessing the collected data
- Performing exploratory data analysis
- Analyzing location-wise car availability
- Analyzing popular car models
- Studying fuel and transmission distributions
- Analyzing price trends
- Generating meaningful business insights

## 🎯 Objectives

1. Scrape used car data from Cars24.
2. Create a structured dataset from the scraped information.
3. Clean and preprocess the collected data.
4. Analyze used car availability across locations.
5. Analyze popular car models.
6. Study fuel and transmission distributions.
7. Analyze price patterns.
8. Generate business insights from the data.

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
